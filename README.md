# Inmobiliaria Rincón Bedoya (INM R‑B)

Aplicación web para la gestión integral de inmuebles de Inmobiliaria Rincón Bedoya (Inmobiliaria R‑B), desarrollada con React + Vite, Firebase y Tailwind CSS. Permite administrar propiedades urbanas y rurales, arriendos, procesos legales asociados y comunicación con clientes.

## 🚀 Demo en producción

- Sitio en línea: https://inmobiliaria-ryb-y-asociados.web.app

## 🧱 Tecnologías principales

- **React + Vite** para la SPA y la experiencia de usuario.
- **Firebase Hosting** para despliegue y CDN.
- **Firebase Cloud Firestore / Realtime Database** (si aplica) para datos.
- **Firebase Cloud Functions** (si aplica) para lógica de backend.
- **Firebase Cloud Messaging** (si aplica) para notificaciones push.
- **Tailwind CSS** para estilos y diseño responsivo.

## ✨ Funcionalidades clave

- Gestión de inmuebles urbanos y rurales (venta y arriendo).
- Organización de información jurídica de los inmuebles (saneamientos, procesos de pertenencia, sucesiones, etc.).
- Panel tipo inmobiliaria para visualizar propiedades y estados.
- Diseño responsivo para escritorio y móvil.
- Integración con servicios de Firebase para autenticación, datos y/o notificaciones (según configuración del proyecto).

## 🛠️ Requisitos

- Node.js (versión LTS recomendada)  
- npm  
- Cuenta de Firebase con un proyecto configurado  
- Git (para clonar y versionar el código)
