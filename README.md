# Inmobiliaria Rincón Bedoya & Asociados

Plataforma para gestionar propiedades, clientes y contratos.

## Cómo instalar

1. Clona el proyecto
2. Ejecuta: npm install
3. Ejecuta: npm run dev
4. Abre: http://localhost:5173

## Tecnologías usadas

- React
- Firebase
- Tailwind CSS
